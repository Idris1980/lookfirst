GitHub

Copied code from an AI assistant, a forum or a tutorial? LookFirst reads it, without running it, and shows what it would build or touch: servers, open ports, files on your computer, websites it talks to, packages it installs. Then it explains the risks in plain English.

🔒 Everything happens in your browser. Your code is not sent anywhere: this page can only load its own files.

Choose files, or a whole folder. They are read here and never uploaded.
