# Cloud service icons

The icons in this folder are not covered by LookFirst's MIT license. They belong to Microsoft and to Amazon Web Services, and LookFirst uses them only to draw architecture diagrams of what code would build, which both allow.

- `azure-*.svg`: [Azure architecture icons](https://learn.microsoft.com/en-us/azure/architecture/icons/), version 24. Microsoft permits the use of these icons in architectural diagrams, training materials, or documentation; all other rights are reserved by Microsoft.
- `aws-*.svg`: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/), release 2026-07-31. AWS allows customers and partners to use them to create architecture diagrams.

The files are copied unchanged. When a report draws them, each icon's internal ids get a prefix so that two icons on one page cannot clash; their shapes and colours are never changed, cropped or rotated, and the product name is shown next to each icon, as both guidelines ask.

To update them, download the packages from the two pages above and copy the same files again.
